# Camera UI visual references

Original user-supplied images, preserved without resizing or annotation. Device names and physical states are the user’s labels; image dimensions are not hardware specifications.

- [Samsung Fold8](samsung-fold8-camera/README.md): seven captures covering cover, unfolded without rotation, unfolded with rotation, and tap-to-focus feedback.
- [iPhone Duo](iphone-duo-camera/README.md): cover and unfolded without rotation.
- [Traditional iPhone](traditional-iphone-camera/README.md): portrait camera composition.

The current Android design learns from proximity of capture controls, restrained mode selection, circular zoom selection, preview overlays and orientation-dependent placement. It preserves Recon’s horizontal mode/queue gesture semantics. These images do not establish hidden interactions, sensor metadata, optical-lens capabilities or an iOS implementation scope.

See the [prototype contract](../prototypes/README.md) and [mode/zoom behavior](../prototypes/COMPONENT-CONTRACT.md).
